Avec LangChain4j

Tu écris simplement :

Assistant assistant =
        AiServices.builder(Assistant.class)
                .chatModel(chatModel)
                .build();

Tu ne fournis aucune implémentation.

Alors comment est-ce possible ?

LangChain4j utilise un Proxy Dynamique

Java possède une classe très puissante :

java.lang.reflect.Proxy

Cette classe est capable de fabriquer une classe à l'exécution


Assistant (interface)

↓

Proxy.newProxyInstance()

↓

AssistantProxy (créée en mémoire)

↓

assistant.chat(...)
La classe AssistantProxy n'existe pas dans ton projet.

Elle est générée automatiquement au démarrage.

public class AssistantProxy implements Assistant {

    @Override
    public String chat(String message) {

        // Construire le prompt

        // Ajouter les SystemMessage

        // Ajouter la mémoire

        // Appeler Ollama

        // Retourner la réponse

    }

}


Que se passe-t-il lorsque tu fais :
assistant.chat("Bonjour");

Le flux est :

Ton code

↓

AssistantProxy.chat()

↓

Lit les annotations

↓

Construit le prompt

↓

Appelle Ollama

↓

Reçoit la réponse

↓

Retourne un String
