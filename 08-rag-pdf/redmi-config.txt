C'est très important.

Un Vector Store ne stocke pas uniquement un vecteur.

Il stocke :

Embedding
+
Texte original
+
Métadonnées

Exemple :

{
 "text":
 "Spring Boot utilise Spring MVC",

 "vector":
 [
   0.12,
   0.54,
   -0.21
 ],

 "metadata":
 {
   "source":"springboot.pdf",
   "page":10
 }
}

C'est pour cela qu'on utilise :

EmbeddingStore<TextSegment>
3. InMemoryEmbeddingStore
return new InMemoryEmbeddingStore<>();

Cela signifie :

Stocke les embeddings dans la mémoire RAM.

Parce que nous voulons comprendre le mécanisme.
